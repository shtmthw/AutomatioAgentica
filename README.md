# AutomatioAgentica

**A code-only video production pipeline.** This repository turns a written script
into a finished, narrated, subtitled educational video. Every frame of animation, the
voice-over, the subtitles and the background music are generated by Python. No video
editor, stock footage or recorded audio is involved.

The video it currently produces is **"What is Agentic AI?"**, a ~10½-minute
introductory lesson for complete beginners:

- **Hindi narration** (ElevenLabs Eleven v4, voice "Adam")
- **English subtitles**, timed sentence by sentence against the narration
- **English on-screen text**, minimal dark animation style (Manim)
- 9 chapters: AI models → what an agent is → chatbot vs agent → the agent loop →
  tools → a real bug-fix walkthrough → risks and safeguards → what's next

Animation, voice and subtitles are all driven by the same word-level timings, so
they stay in sync. Edit a line in the script and rebuild; only that line is re-voiced.

> New here (human or AI)? Read **[ANIMINFO.md](ANIMINFO.md)**. It is the full
> playbook: tech choices, what works, mistakes to avoid, and how to reproduce the result.

## Quick start

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r pyproject.toml
echo "ELEVENLABS_API_KEY=sk_..." > .env          # or use the free fallback voice below
.venv/bin/python -m tools.build all -j 5          # voice → render → assemble (~10 min)
# free draft without ElevenLabs credits:
AGENTIC_TTS_ENGINE=edge .venv/bin/python -m tools.build all -j 5
```

Requires `ffmpeg` (with libass), `uv`, and the fonts Inter, JetBrains Mono and Noto Sans Devanagari.

## Output (generated, not committed)

This repository tracks **code only**. Voice clips, music, videos and subtitles are
git-ignored and are regenerated by `python -m tools.build all`. Re-voicing the full
narration uses about 6.75k ElevenLabs credits, or nothing with the free `edge` fallback.

| File | What it is |
|---|---|
| `output/agentic_ai_intro_hi_1080p.mp4` | Final video, 1920×1080, 30 fps, English subtitles burned in |
| `output/agentic_ai_intro_hi_1080p_softsubs.mp4` | Same video with the subtitles as a switchable track |
| `output/agentic_ai_intro_hi_1080p.srt` | English subtitles on their own (e.g. for YouTube) |
| `output/narration_script_hi_en.md` | Hindi narration + English subtitles, with timestamps |
| `output/archive_bangla/` | Subtitles/script of the earlier Bangla version |

## Structure

```
agentic_video/            shared library
  narration.py            ← THE SCRIPT: Hindi narration + English subtitle per line
  pronunciation.py        ← how words are SAID (e.g. "AI" -> "एआई")
  narration_bn_archive.py the earlier Bangla script (not used)
  config.py               voice, fps, loudness targets, scene order
  style.py                palette, fonts, type scale, text helpers
  icons.py                line icons drawn from primitives (no image files)
  components.py           Zone, Card, Pill, Bubble, Terminal, CodeEditor, Browser, arrows ...
  voice.py                VoiceScene: syncs animation to narration and logs cue times
scenes/                   one file per section, s01_intro.py … s09_outro.py
tools/
  tts.py                  narration clip per line (cached) + word timings
  say.py                  hear any word/sentence in the narrator's voice
  eleven.py               ElevenLabs client: account, voice library, samples, speech + timings
  music.py                synthesised ambient background music
  subtitles.py            SRT/ASS generation from word timings
  build.py                render → concat → mix → subtitles → final MP4
  preview.py              fast low-res render + contact sheet for one scene
  export_script.py        writes the narration script as Markdown
assets/voice/             generated voice clips + manifest.json (timings)
assets/music/             generated music
build/                    intermediate files (safe to delete)
```

## How synchronisation works

1. `tools/tts.py` synthesises each narration line separately and stores its
   duration and **word-level timings** in `assets/voice/manifest.json`.
2. Each scene drives its animation from those timings:
   ```python
   with self.say("s05_07") as v:              # narration line starts here
       self.wait_until(v.word("Browser"))     # jump to the spoken word
       self.play(FadeIn(browser))
   ```
   The scene waits for the line to finish before the next one starts, and
   writes the exact start time of every line to `build/cues/<section>.json`.
3. `tools/build.py` places the voice clips at those times, adds the
   music (ducked under the voice), and builds subtitles from the same timings.
   Picture, voice and subtitles can't drift apart.

## Setup

Requirements: Linux/macOS, `ffmpeg` (with libass), `uv`, and the fonts
**Noto Sans Bengali**, **Inter** and **JetBrains Mono**.

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r pyproject.toml
```

The narration uses Microsoft neural voices via `edge-tts` (the same package as
`pipx install edge-tts`), so generating it needs an internet connection.
Clips are cached in `assets/voice/`, so rendering and assembling work offline after that.

### Voice (ElevenLabs Eleven v4, "Adam")

The narration uses **ElevenLabs** with the `eleven_v4` model (the workflow from
the ElevenLabs masterclass video) and the built-in voice **Adam**
(`ELEVEN_VOICE_ID` in `config.py`). On the free plan, ElevenLabs does not allow
Voice Library voices over the API ("Free users cannot use library voices via the
API"), which is why a built-in voice is used. With a paid plan, any library voice
ID can go into `ELEVEN_VOICE_ID`.

- API key: `.env` in the project root, `ELEVENLABS_API_KEY=...` (gitignored)
- Free plan: 10,000 credits per month. The full Hindi narration is about 6,750 characters.
  Only edited lines are regenerated. Subtitle-only edits cost nothing.
- Free fallback with no credits: `AGENTIC_TTS_ENGINE=edge .venv/bin/python -m tools.build all`
  (Microsoft `hi-IN-MadhurNeural`)
- Commercial use (e.g. a monetised channel) needs a paid ElevenLabs plan.
- Useful: `python -m tools.eleven account | voices | sample <voice_id>`

## Changing words and pronunciation

There are three levels. Each one changes only what is **spoken**, except the
first, which also changes the subtitles:

**1. Change what is said or shown.** Each line in `agentic_video/narration.py` is

```python
("s05_12", "Browser ने फिर काम किया। और इस बार नतीजा आया, ...",      # Hindi: spoken
           "The browser works again. And this time the result ..."),   # English: subtitle
```

Keep the same number of sentences in both. Subtitle sentence *i* is shown while
Hindi sentence *i* is spoken.

**2. Change how a word is pronounced everywhere.** Add it to
`agentic_video/pronunciation.py`. The subtitles keep the original spelling:

```python
PRONUNCIATION = {
    "AI": "एआई",         # spoken "E-AYE"; subtitles still show "AI"
    "LLM": "एल एल एम",   # add your own like this
}
```

**Listen before rebuilding.** This takes a few seconds and writes MP3s to `output/samples/`:

```bash
.venv/bin/python -m tools.say "आपने एक AI Agent से कहा"   # with the dictionary (uses credits on ElevenLabs)
.venv/bin/python -m tools.say "एआई" "ए आई" "ए-आई"         # compare spellings
.venv/bin/python -m tools.say --raw "AI"                     # without the dictionary
```

**Apply it to the video:**

```bash
.venv/bin/python -m tools.build all -j 5   # re-voices only the changed lines, re-renders, re-encodes
```

Tips for respelling: write the word the way it should sound in Devanagari
(`एआई`, `क्लॉड`). Spaces or hyphens between letters (`ए आई`) make it more clearly
letter-by-letter. Timing cues in the scenes, such as `v.word("AI")`, keep
working after a word is respelled.

## Common tasks

```bash
# Full build from scratch (≈3 min render + ≈4 min assemble on 12 cores)
.venv/bin/python -m tools.build all -j 5

# Change narration: edit agentic_video/narration.py, then
.venv/bin/python -m tools.build voice           # only changed lines are re-synthesised
.venv/bin/python -m tools.build render s05      # re-render the affected scene(s)
.venv/bin/python -m tools.build assemble        # re-mix and re-encode (≈4 min)

# Iterate on one scene's animation quickly (480p + contact sheet)
.venv/bin/python -m tools.preview s05           # -> build/preview/s05_sheet.jpg
.venv/bin/python -m tools.preview s05 --audio   # preview video with voice

# Export the narration script
.venv/bin/python -m tools.export_script
```

Settings in `agentic_video/config.py`:
- `VOICE`: the narrator (`bn-BD-PradeepNeural`)
- `VOICE_RATE`, `VOICE_PITCH`: pacing and depth (re-run `voice` after changing)
- `MUSIC_LUFS`, `DUCK_DB`: how loud the music is and how much it dips under the voice
- `BURN_SUBTITLES`: turn burned-in subtitles off
- `FPS`
