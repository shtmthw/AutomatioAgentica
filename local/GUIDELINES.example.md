# My production guidelines

Copy to `local/GUIDELINES.md` (gitignored) and edit. The agent reads this file on top of
"Production guidelines" in `AGENTS.md`. Where the two disagree, this file wins, but the
hard rules of `AGENTS.md` still apply: approval before paid credits, separate subtitle
files only, nothing cut from the script, voices fixed once a production is made.

Write one numbered direction per point, as you would brief an editor:

1. **Length:** aim for 8–10 minutes; tell me before approval if the script runs longer.
2. **Recap:** close with a 30-second recap of the topics (same rule as the house guideline).
3. **On-screen text:** keep pop-ups to three words.
4. **Versions:** English only unless I ask for the Hindi dub.
