# Production plan: What is a tool call? (pipeline demo)

Minimal house style (dark canvas, thin outlines, one accent per concept: blue = model,
teal = tool / result). English on-screen text. 1920x1080, 30 fps.

## 01. Tool calls
TIME: 0:00–0:12

A model chip on the left and a tool card (terminal icon) on the right. When "tool call"
is said, the title "tool call" appears and a request arrow grows from the model to the
tool. On "request", a small request pill travels along the arrow into the tool, which
glows. On "result", a result pill ("✓ 3 passed") travels back and the model glows teal.
